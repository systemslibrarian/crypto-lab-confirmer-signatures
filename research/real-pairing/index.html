What do Bob’s equations check?

Each OR branch uses a different role key. C is that public key, D its group generator, and x the private scalar. A is derived from the encrypted signature; B from the message hash and the other role’s public key. Bob reconstructs these values from the public object.

Confirmation

The witness satisfies C = x·D and A = B^x. For each branch, Bob checks:

z_key = b·D + c·Cz_pair = B^b · A^c

The prover fixed both z values before Bob’s challenge.

Candidate disavowal

The witness satisfies C = x·D and A ≠ B^x. For each branch, Bob checks:

z_key = u·D − v·Cz_pair = β^c · B^u / A^v

β must be a nonidentity element of the order-q target group. This condition is checked, not assumed.

The two branch challenges must add to Bob’s challenge: c₁ + c₂ = c (mod q). All scalar arithmetic is modulo the BLS12-381 subgroup order. Point equations use addition; target-group equations use multiplication.

A prover knows one role secret and simulates the other branch. The public equations check both branches. See the evidence view for the exact derivation and the security properties this does not establish.
